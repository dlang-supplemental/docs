= D Lang Supplemental Docs

Documentation hub for the dlang-supplemental organization, built with Antora and https://github.com/antora-supplemental/valentus-theme[valentus-theme].

link:https://dlang-supplemental.github.io/docs/[Explore the docs] ·
link:https://github.com/dlang-supplemental/docs/issues[Report Bug] ·
link:https://github.com/dlang-supplemental/docs/issues[Request Feature]
endif::[]

== About The Project

The site header logo is the org **D+** mark in `supplemental-ui/img/logo.svg` (overrides the Valentus default via `ui.supplemental_files`).

Docs are pulled from component repositories (asciidoctor-dlang, densor, fluidsync-daemon, vector-store-dlang, vibe-search-core, vibe-search-desktop, graphrag-indexer, opentui-d, avalonia-d, and others). This repo's own content is under `docs/` (portal and nav).

== Getting Started

* Production (fetch from GitHub): `pnpm build` (uses `antora-playbook.yml`)
* Local (sibling repos): `pnpm run build:local` (uses `antora-playbook-local.yml`)
