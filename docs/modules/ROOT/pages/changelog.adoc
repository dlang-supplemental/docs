== 2026-10-16

Portal hub updates.

=== Hub index nav label Overview

* Hub xref:index.adoc[Overview] uses `:navtitle: Overview` and the first nav entry **Overview**; the page H1 is **D Lang Supplemental Portal** (Dev-Centr-style split: component **Home**, portal name in content, overview label in the sidebar).

=== Hub component `home` (avoid `/docs/docs/`)

* `AGENTS.md` links the canonical Dev-Centr write-up link:https://docs.devcentr.org/home/publishing/hub-home-component.html[Hub home component^] and skill `hub-home-overview`.
* Hub Antora component `name` is `home` (was `docs`), matching Dev-Centr and antora-supplemental hub conventions. Meta-docs stay in this repo's `docs/` content tree; the published URL segment is `/home/` under the GitHub Pages site base (`…/docs/home/`), not `…/docs/docs/`.
* Post-build step mirrors hub HTML under `…/docs/docs/` with client redirects to the matching `…/docs/home/` page so old bookmarks keep working.
* `site.start_page` is `home::index.adoc`; hub `docs/antora.yml` keeps `start_page: ROOT:index.adoc`.
* Keyword listings still use `lib/page-context-keywords-host.js` on the `home` component at `/docs/keywords/` (`page-context-keyword-base` unchanged).

=== Portal as site and component home

* `site.start_page` points at xref:index.adoc[Overview] (was `asciidoctor-d:ROOT:index.adoc`), so the site root redirect, header title link, and breadcrumb home chip land on the hub instead of a product component.

=== SoftNav breadcrumbs and page TOC

* Detail links append **Changelog** in the breadcrumb (`… / Changelog / Detail title`) instead of replacing that crumb with the detail title.
* Right-rail page TOC rebuilds after a soft navigation. The previous heading selector threw, so the rail stayed on the page you left.
* `@antora-supplemental/facto-stack` **v0.2.4** pulls `@antora-supplemental/soft-nav-page-toc` **v0.1.6** (script URL, `:hide-page:` meta, and the parent crumb on a hard load).
+
See xref:changelog-details/2026-10-16 - soft-nav-breadcrumb-toc.adoc[Detailed changelog].

=== Changelog heading format

* Index and detail pages use `== YYYY-MM-DD` (date only) and `===` topic lines with short descriptions; `:toclevels: 3` lists topics in the page TOC.
* Changelog detail pages declare `:hide-page:` and `:navtree-parent: changelog.adoc` for nav-drift audits, breadcrumb trails, and SoftNav nav-tree injection.
+
See xref:changelog-details/2026-10-16 - changelog-em-dash-headings.adoc[Detailed changelog].

=== Linkinator hover bar and chrome exclusions

* `@antora-supplemental/linkinator` **v0.1.2+** shows Wayback controls in a hover bar on article links only (not header, footer, or page-context metadata).
* Extension display name is **Linkinator** (`v0.1.3` registry metadata; npm package id unchanged).
+
See xref:changelog-details/2026-10-16 - linkinator-hover-chrome.adoc[Detailed changelog].

=== Learning about D media page

* Curated xref:learning-about-d.adoc[Learning about D] hub page (maintainer list via PR/issue); includes Wookash Podcast interview with Lewis Nicolle on why D.
+
See xref:changelog-details/2026-10-16 - learning-about-d-media.adoc[Detailed changelog].

=== Facto stack and site search

* Playbook requires `@antora-supplemental/facto-stack` once (compose Antora extension); Lunr, `@antora-supplemental/antora-search-chat`, page-context, nav typology, link tooling, and related members register from the pack so the footer lists depth-1 imports.
+
See xref:changelog-details/2026-10-16 - facto-stack-lunr-search.adoc[Detailed changelog].

=== SoftNav TOC and in-page hash jumps

* Fixed hub `soft-nav.js` treating sidebar TOC hash links as cross-page soft loads when folder URLs used a trailing slash (`/changelog/#section` vs `/changelog/`). Same-page `#` clicks now scroll the article; soft fetch applies `#` after swaps when needed.

=== SoftNav page TOC after detail links

* `@antora-supplemental/facto-stack` **v0.2.3** registers `@antora-supplemental/soft-nav-page-toc` so the right-rail page TOC rebuilds when SoftNav swaps to xref:changelog-details/[changelog-details] and other in-component pages. Upstream proposal: link:https://docs.antora-supplemental.org/docs/ROOT/proposals/soft-nav-page-toc.html[SoftNav page TOC and nav-hidden pages^].

=== SoftNav scroll, TOC, and nav-hidden children

* Hub `soft-nav.js` keeps the left nav tree stable on soft loads (`swapNav` off), scrolls to top on cross-page navigation, rebuilds the right-rail TOC, soft-navigates same-component nav links, patches breadcrumbs for `:hide-page:` entries, and injects them under their `:navtree-parent:` (Changelog → detail) on hard and soft loads.

=== Nav tree parent registry

* `navtree-registry.json` and a `;; navtree-parent-association:` line in `nav.adoc` declare parent links for `:hide-page:` entries when path heuristics are not enough (for example xref:proposals/tgc-design-0.1.0.adoc[tgc design 0.1.0] under xref:proposals/index.adoc[Proposals]).

=== Left nav text filter (site-nav-tree)

* Removed hub-only filter assets (supplemental `nav-menu`, `nav-tree-filter` CSS/JS). A sticky label filter belongs on `@antora-supplemental/site-nav-tree` with `filter: true` when that extension is registered (this hub still uses facto-stack single-component sidebar per page).
* `@antora-supplemental/facto-stack` **v0.2.5** ships site-nav-tree with `filter: true` by default when you enable pack `siteNavTree` (unchanged for this single-component hub until site-nav-tree is opted in).

=== Facto stack pin v0.2.6

* Bump `@antora-supplemental/facto-stack` to **v0.2.6** (continues to pin `@antora-supplemental/soft-nav-page-toc` **v0.1.6** for aside TOC rebuild and nav-hidden compose).
