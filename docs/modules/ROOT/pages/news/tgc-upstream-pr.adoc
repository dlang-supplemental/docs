We submitted an opt-in *thread-local garbage collector* for D—registered as **`tgc`**—to upstream DMD/druntime.

*Upstream PR:* https://github.com/dlang/dmd/pull/XXXX[`dlang/dmd` PR] (update after open).

*Design write-up:* xref:blog/thread-local-gc-tgc.adoc[Thread-local garbage collection (`tgc`) for D].

== Why it matters

D isolates thread-local data by default, but the standard GC still uses one process-wide heap and stop-the-world collection.
That pauses `@nogc` realtime threads whenever any other thread collects.
`tgc` gives each thread a private heap and collects without a global pause, selected only when you ask for it:

[source,console]
----
./app --DRT-gcopt=gc:tgc
----

The default conservative GC is unchanged.
Informally this is sometimes called a “realtime GC”; the runtime name is `tgc`.
