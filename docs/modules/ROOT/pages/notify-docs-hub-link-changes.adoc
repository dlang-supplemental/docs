:navtitle: Hub link-cache invalidation

Live site: https://dlang-supplemental.github.io/docs[+].

Multi-repo hubs rebuild when a content repo *pokes* the playbook repo — same star pattern as `extension-updated` (see link:https://docs.antora-supplemental.org/home/antora-deployment/#_auto_rebuild_when_content_sources_or_extensions_update[Antora deployment: auto-rebuild^]).

**Link-cache invalidation** adds optional *surgical* recheck hints for `@antora-supplemental/link-validator` (env `LINK_VALIDATOR_INVALIDATE_*`, v0.2.2+ via Facto stack) while the hub still runs a full Antora generate and GitHub Pages deploy.

Agent skill: `docs-hub-link-invalidate` (`dev-centr/agent-rules`).

== Hub subscriber (this repo)

Workflow: `.github/workflows/deploy.yml` listens for:

* `push` to `main`
* `pull_request` (build only)
* `workflow_dispatch`
* `repository_dispatch` types `extension-updated`, `link-cache-invalidate`

On `link-cache-invalidate`, the build maps `github.event.client_payload` to:

| Payload field | Build env | Notes |
|===|===|===
| `sources` | `LINK_VALIDATOR_INVALIDATE_SOURCES` | Comma-separated string or JSON array |
| `urls` | `LINK_VALIDATOR_INVALIDATE_URLS` | Comma-separated string or JSON array |
| `ref` | checkout ref | Default `main` when omitted |
| `source`, `sha` | (log context) | Calling repo |

== Fire a dispatch with `gh`

Org secret **`DOCS_HUB_DISPATCH_TOKEN`**: fine-grained PAT or GitHub App token with permission to create `repository_dispatch` on `dlang-supplemental/docs`.

[source,shell]
----
gh api repos/dlang-supplemental/docs/dispatches \
  -f event_type=link-cache-invalidate \
  -f client_payload[source]=dlang-supplemental/asciidoctor-d \
  -f client_payload[ref]=main \
  -f client_payload[sha]=$(git rev-parse HEAD) \
  -f client_payload[sources]=docs/modules/ROOT/pages/index.adoc
----

== Reusable caller workflow (org default)

Path: `dlang-supplemental/.github/.github/workflows/docs-hub-link-cache-invalidate-dispatch.yml`

[source,yaml]
----
jobs:
  notify:
    uses: dlang-supplemental/.github/.github/workflows/docs-hub-link-cache-invalidate-dispatch.yml@main
    secrets:
      DOCS_HUB_DISPATCH_TOKEN: ${{ secrets.DOCS_HUB_DISPATCH_TOKEN }}
    with:
      hub_repo: dlang-supplemental/docs
      sources: 'docs/**'
----

Exemplar thin caller: `dlang-supplemental/asciidoctor-d/.github/workflows/notify-docs-hub-link-invalidate.yml`.
