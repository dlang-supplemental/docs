= Learning about D
:description: Curated talks, podcasts, and other media for getting oriented to the D programming language.
:navtitle: Learning about D

This page lists **maintainer-curated** media about D — podcasts, interviews, conference talks, and similar introductions.
It is not a community wiki: new entries land here through a pull request or issue on the https://github.com/dlang-supplemental/docs[docs hub repo], so the list stays small and vetted.

If you know a strong resource, open an issue with the link and a sentence on why it belongs; maintainers decide whether to add it.

== Essays and longer orientation

* link:https://devcentr.org/blog/2026-11-19-bends-parallel-bet-and-what-d-should-steal-instead[Bend's Parallel Bet—and What D Should Steal Instead] (DevCentr blog) — how Bend's automatic-parallelism story compares to D's systems strengths, what incremental improvements are realistic, and where ecosystem momentum matters more than new syntax.
* link:https://docs.devcentr.org/general-knowledge/explanation/languages/bend/[Bend] — what the language is (interaction nets), separate from the blog comparison.
* link:https://docs.devcentr.org/general-knowledge/explanation/languages/unison/[Unison] — content-addressed definitions and a bytecode runtime, not a native compiler.
* link:https://docs.devcentr.org/general-knowledge/explanation/languages/unison-and-d/[Unison and D] — why the two jobs do not collapse into one language.
