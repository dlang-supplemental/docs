= Learning about D
:description: Curated talks, podcasts, and other media for getting oriented to the D programming language.
:navtitle: Learning about D

This page lists **maintainer-curated** media about D — podcasts, interviews, conference talks, and similar introductions.
It is not a community wiki: new entries land here through a pull request or issue on the https://github.com/dlang-supplemental/docs[docs hub repo], so the list stays small and vetted.

If you know a strong resource, open an issue with the link and a sentence on why it belongs; maintainers decide whether to add it.
