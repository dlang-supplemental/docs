== Changelog heading format

* Portal xref:changelog.adoc[changelog] index: `== YYYY-MM-DD` (date only on level-2 headings) and `===` short topic lines for every ship; `:toclevels: 3` lists topics in the page TOC without long em-dash summaries on date lines.
* Optional one-line day blurbs under a date (plain text, not headings) when several same-day items share a theme — keep them short (roughly eight words or fewer), like “Portal hub updates.”
* xref:changelog.adoc#_changelog_details[changelog-details] pages use `= YYYY-MM-DD` and `==` matching the index `===` title; filenames stay `YYYY-MM-DD - slug.adoc`.
* House skill `owned-changelog` documents the layout and requires conforming older entries whenever a changelog is edited.
